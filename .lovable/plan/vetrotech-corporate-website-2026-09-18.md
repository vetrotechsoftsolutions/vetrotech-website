# VetroTech Corporate Website

## Build scope
- Replace the placeholder homepage with one polished, single-page corporate consultancy site using the supplied business details and copy.
- Create the full page flow: sticky navigation, hero, trust stats, about, services, solutions, industries, differentiators, process, reviews, CTA, contact form, and footer.
- Keep all major navigation items as smooth-scroll links because the brief explicitly describes a single-page experience.

## Visual direction
- Use a restrained enterprise palette: deep navy, royal blue, crisp white, pale gray, and small cyan accents.
- Pair strong sans-serif typography with generous whitespace, compact content widths, thin borders, and subtle elevation.
- Build original technology visuals from CSS and line icons: connected systems, architecture blocks, dashboard modules, and process paths without stock imagery or cartoon styling.
- Add quick fade-up reveals, restrained hover movement, navbar state transitions, and reduced-motion support.

## Components and behavior
- Build reusable sections for Navbar, Hero, Stats, About, Services, Solutions, Industries, Why VetroTech, Process, Reviews, CTA, Contact, and Footer.
- Add a working keyboard-accessible mobile menu and sticky header that changes appearance after scrolling.
- Add semantic, accessible forms with client-side validation, inline field errors, submission feedback, and no invented delivery service or email address.
- Keep the Google review destination configurable; if absent, the button will open a useful notice rather than an invented link.
- Make phone and internal navigation links functional. Keep privacy and terms visible without inventing legal copy.

## SEO and trust
- Add the exact requested title and description, Open Graph fields, canonical URL, Twitter card, and structured Organization/LocalBusiness data using only supplied facts.
- Preserve favicon support and use accurate address, phone, rating, and review count.
- Avoid fabricated clients, awards, testimonials, case studies, staff counts, and experience claims.

## Validation
- Check the latest build diagnostics after implementation.
- Test navigation, mobile menu, form validation, success state, internal links, and horizontal overflow.
- Visually inspect the page at 1440, 1280, 1024, 768, 390, and 360 pixels and correct layout or typography issues found.
